# Smart City Energy Consumption Trends & Sustainability Dashboard

## Project Overview
Developed as part of my IBM Internship, this project focuses on analyzing electricity consumption patterns using an interactive Power BI dashboard.

The dashboard provides insights into hourly energy consumption, average load comparisons across different regions, peak demand periods, and consumption trends to support better energy management and sustainability planning.

## Dataset
Hourly Energy Consumption Dataset – Kaggle

Source: https://www.kaggle.com/datasets/robikscube/hourly-energy-consumption

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Hourly energy consumption analysis
- Regional energy load comparison (AEP, COMED, PJME)
- Average energy consumption trends
- Peak demand analysis
- Interactive visualizations
